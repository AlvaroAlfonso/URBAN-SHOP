💟💟 URBAN&SHOP (Desarrollador Web Full Stack & Diseñador UX/UI). 🩵🩵

✨✨Es una plataforma de comercio electrónico dedicada a la venta de ropa urbana reciclada y sostenible. Este proyecto fue desarrollado como parte de un trabajo semestral para las materias de Diseño UX, Arquitectura de Software y Diseño Web. ✨✨

✨✨Proceso de Desarrollo:

✨Investigación: Realizamos una exhaustiva investigación de mercado para comprender las necesidades y preferencias de nuestro público objetivo, así como las tendencias en moda sostenible.

✨Diseño UX: Creamos diseños de interfaz de usuario (UI) y experiencia de usuario (UX) en Figma, asegurando una navegación intuitiva y una experiencia de compra agradable. Se aplicaron principios de usabilidad para garantizar que la plataforma sea fácil de usar para todos los usuarios.

✨Arquitectura de Software: Diseñamos una arquitectura de software robusta y escalable, que permite la integración de APIs externas (pasarela de pago) y una API propia (suscripción con envío de correo electrónico de bienvenida).

✨Desarrollo Web: Implementamos el diseño y la arquitectura utilizando tecnologías web modernas, asegurando un rendimiento óptimo y una experiencia de usuario fluida.
